# Exa Web Search

Exa is a personal [Connector](connectors.md). Add an Exa Key in `/console/connectors`,
then select that connection in Chat, an Agent draft, or a Workflow node.
The native provider supports search and contents operations under the frozen catalog contract.
Keys are owned by the account and are never selected from deployment-wide search settings.
The old Web Search and External Integrations configuration variables are retired.
For existing connections follow the [offline upgrade procedure](../tools/connector-migrate/README.md).
